# IEEE DataPort source

The original IEEE DataPort workbooks are not redistributed here. Download the source archive from:
https://ieee-dataport.org/documents/learning-style-identification

Place the downloaded archive in this folder as `LS-IEEE-Dataport.zip`. The external-evaluation script reads `CSHS.xlsx` and `CSMS.xlsx` from the ZIP, selects the audited questionnaire rows, performs the frozen 70/30 split, and fits discretization on the training records only.
