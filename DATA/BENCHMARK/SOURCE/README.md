# UCI benchmark sources

The ten raw benchmark archives are not duplicated in this package. Download them from the UCI Machine Learning Repository using `../benchmark_manifest.csv`, retain the expected filenames, and place the archives in this folder.

This design keeps third-party source data at their authoritative repository. The manifest records the exact source SHA-256 values used in the reported experiments. Some UCI datasets may have dataset-specific access terms; follow the current UCI terms for each source.
